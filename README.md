# 🍪 쿠키런 (Cookie Run) - 웹 게임

바닐라 JavaScript + Canvas 로 만든 쿠키런 스타일의 **엔드리스 러너** 게임입니다.
설치나 빌드 없이 `index.html` 파일만 열면 바로 플레이할 수 있습니다.

---

> 🎮 **바로 플레이** : <https://bshjl25-dotcom.github.io/cookierun-web/>
> 📦 **저장소** : <https://github.com/bshjl25-dotcom/cookierun-web>
>
> ```bash
> git clone https://github.com/bshjl25-dotcom/cookierun-web.git
> ```

## ▶ 실행 방법

**방법 1 (가장 간단)**
`index.html` 파일을 더블클릭해서 브라우저로 엽니다.

**방법 2 (권장)**
로컬 서버로 열면 저장 기능(최고 점수)이 더 안정적으로 동작합니다.

```bash
# 파이썬이 있다면
python -m http.server 8080

# Node.js 가 있다면 (npx)
npx serve .
```

그 다음 브라우저에서 `http://localhost:8080` 접속.

> Chrome / Edge / Safari / Firefox 최신 버전에서 동작합니다.

## 🎮 조작법

| 동작 | 키보드 | 모바일 |
| --- | --- | --- |
| 점프 (2단 점프) | `Space` / `↑` / `W` | 화면 탭 또는 **점프** 버튼 |
| 슬라이드 (숙이기) | `↓` / `S` (누르는 동안) | **슬라이드** 버튼 또는 아래로 스와이프 |
| 급강하 (공중에서) | `↓` / `S` | 슬라이드 버튼 |
| **속도 조절** | `−` / `=` (또는 `[` `]`) | 시작 화면에서 선택 |
| 일시정지 | `P` / `Esc` | 우측 상단 `❚❚` |
| 소리 켜기/끄기 | `M` | 우측 하단 `🔊` |

### 고급 팁
- 점프 키를 **짧게** 떼면 낮게, **오래** 누르면 높게 뜁니다 (가변 점프).
- 점프 직후 `↓` 를 누르면 급강하하며 **착지와 동시에 슬라이드**가 됩니다.
  → "장애물 점프 후 바로 천장 구간"을 통과할 때 유용합니다.
- 젤리를 연속으로 먹으면 **콤보**가 쌓여 점수가 최대 5배까지 오릅니다.

## ⚡ 속도(난이도) 조절

시작 화면의 **속도 (난이도)** 에서 5가지 프리셋을 고를 수 있습니다.

| 프리셋 | 배속 | 시작 속도 | 최고 속도 |
| --- | --- | --- | --- |
| 🐢 아주 느긋 | ×0.7 | 약 23 km/h | 약 55 km/h |
| 🚶 느긋 | ×0.85 | 약 28 km/h | 약 67 km/h |
| 🍪 보통 | ×1.0 | 약 33 km/h | 약 79 km/h |
| ⚡ 빠름 | ×1.3 | 약 43 km/h | 약 103 km/h |
| 🔥 미친 속도 | ×1.6 | 약 53 km/h | 약 127 km/h |

**게임 중 실시간 조절**: `−` / `=` 키를 누르면 5%씩 미세 조정됩니다 (×0.4 ~ ×2.0 범위).
화면 좌측 상단에 현재 속도(km/h)와 배속(`×1.3`)이 표시됩니다.

- 배속은 기본 속도·최고 속도·가속도에 **함께** 적용되고, 장애물 간격도 속도에 비례해 늘어나기 때문에
  어느 배속에서도 공정하게 플레이할 수 있습니다.
- 선택한 배속은 자동 저장되어 다음 실행 때 그대로 유지됩니다.
- 관련 상수: `BASE_SPEED` / `MAX_SPEED` / `SPEED_ACCEL` / `SPEED_PRESETS` (`game.js` 상단)

## ✨ 아이템

| 아이콘 | 효과 |
| --- | --- |
| 🧪 물약 | 에너지 30 회복 |
| 🧲 자석 | 7초 동안 주변 젤리를 끌어당김 |
| ⭐ 별사탕 | 4.5초 무적. 장애물과 부딪히면 장애물이 부서지고 점수 획득 |

- **분홍 대형 젤리** : 점수 +10

## ⚙️ 게임 규칙

- 시간이 지날수록 속도가 빨라지고(기본 최대 880px/s), 장애물 패턴이 어려워집니다.
  시작 화면에서 배속(×0.4 ~ ×2.0)을 바꾸면 전체 난이도가 함께 조절됩니다.
- 장애물에 부딪히면 **에너지가 25 감소**합니다 (1.5초 무적 + 화면 흔들림).
- 에너지가 0이 되면 게임 오버. 에너지 최대치는 캐릭터마다 다릅니다.
- 최고 점수는 `localStorage` 에 저장됩니다.

```
cookierun-web/

├── style.css    # UI 스타일 (반응형 / 모바일 대응)
├── game.js      # 게임 로직 + Canvas 렌더링
└── README.md
```

### game.js 구성
1. 상수 & 유틸
2. DOM 참조
3. WebAudio 사운드 (외부 파일 없이 신디사이저로 생성)
4. 쿠키 캐릭터 데이터
5. 게임 상태
6. 배경 요소 (구름 / 언덕 / 도시 - 도시는 오프스크린 캔버스로 1회만 렌더)
7. 장애물 · 젤리 · 파워업 정의 및 패턴 스폰 (속도 비례 간격)
8. 파티클 & 점수 팝업
9. 게임 흐름 (시작 / 일시정지 / 사망 / 결과)
10. 조작 (키보드 + 터치 + 스와이프)
11~12. 업데이트 & 렌더링
13. HUD 동기화
14. 메뉴 (쿠키 선택 카드)
15~16. 초기화 & 메인 루프

## 🔧 개발 메모

- 캔버스 논리 해상도는 `960 x 540` 고정이며, CSS 로 화면에 맞게 스케일됩니다 (DPR 대응).
- 물리 수치: 중력 `2900`, 점프 `-1060`, 2단 점프 `-920` (px/s², px/s).
- 40px = 1m 로 환산해 HUD 에 km/h 로 표시합니다.
- 장애물 간격은 `현재 속도 × 1.0 ~ 1.6` 으로 계산해 속도가 올라가도 반응 시간이 일정합니다.
- 콘솔에서 `window.__cookierun` 으로 게임 상태를 확인/조작할 수 있습니다 (디버그용).
